# Python Blue Animated Heart 💙

An elegant Python graphics project that animates a vibrant blue mathematical heart pattern with glowing sparkle effects using standard `turtle`, `math`, and `colorsys` modules.

## 📌 Features

* 💙 **Gradient Blue Tones:** Smooth transitions from deep royal blue to bright cyan using `colorsys.hsv_to_rgb`.
* 📐 **Mathematical Curve:** Parametric equation mapping precise heart dimensions.
* ✨ **Sparkle Particle Effects:** Dynamic perimeter bursts generated with random heading vectors.
* ⚡ **Smooth Frame Updates:** Controlled screen refresh rates using `tracer(0)` and `ontimer`.

## 🚀 Getting Started

### Prerequisites

* **Python 3.x** installed on your machine.
* Standard Python libraries used (`turtle`, `math`, `colorsys`, `random`) — no third-party package installation required.

### Running the Code

1. Open your terminal or command prompt.
2. Navigate to the project folder:
   ```bash
   cd python-blue-heart
   ```
3. Run the script:
   ```bash
   python main.py
   ```
